# Privacidad

Toribio Radio no crea cuentas, no incluye publicidad y no incorpora telemetría propia.

Para cargar el directorio, la aplicacion consulta el servidor de Radio Browser y puede usar el servidor comunitario compatible `radios.axiomaudio.com` cuando el principal no esta disponible.

Al utilizar la aplicación se producen estas conexiones:

1. Se consulta la API pública de Radio Browser para descargar el catálogo solicitado.
2. Al reproducir una emisora, la Wii U se conecta directamente al servidor indicado por esa emisora.

Como ocurre con cualquier conexión a Internet, Radio Browser, la emisora, su proveedor de alojamiento y los intermediarios de red pueden recibir la dirección IP pública, la fecha, la duración aproximada de la conexión y el identificador técnico de la aplicación. El proyecto Toribio Radio no administra esos servidores ni controla sus políticas.

La aplicación no envía contraseñas, contactos, archivos personales ni identificadores de la cuenta Nintendo. No se deben colocar credenciales dentro de enlaces de emisoras o archivos de configuración.

Los enlaces pueden cambiar o dirigir a proveedores externos. HTTPS utiliza el paquete de autoridades certificadoras incluido en la aplicación; la beta continuará validándolo en diferentes consolas y redes antes de una versión 1.0.
