Estructura de destino para Aroma
================================

dist/toribio-radio.wuhb       -> sd:/wiiu/apps/toribio-radio.wuhb
dist/tapo-wiiu-viewer.wuhb    -> sd:/wiiu/apps/tapo-wiiu-viewer.wuhb
dist/toribio-browser.wuhb     -> sd:/wiiu/apps/toribio-browser.wuhb

Antes de copiar Toribio Radio, elimina sd:/wiiu/apps/wiiu-radio.wuhb y
cualquier versión anterior con otro nombre para evitar iconos duplicados.

El catálogo de la versión actual se obtiene de Radio Browser. El archivo
config/radio/stations.ini es una plantilla para una función futura y todavía
no es leído por la aplicación.
