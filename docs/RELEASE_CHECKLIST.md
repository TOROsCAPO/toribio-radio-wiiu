# Lista de control para cada lanzamiento

## Código y seguridad

- [ ] No hay tokens, contraseñas, claves privadas ni rutas personales.
- [ ] La compilación parte de una carpeta limpia.
- [ ] El catálogo y la reproducción no bloquean la interfaz.
- [ ] La verificación HTTPS está habilitada y probada en Wii U real, o la versión está marcada claramente como beta.
- [ ] Se probaron selección de país, filtro, reproducción, pausa, detener, cambio L/R y regreso B.

## Licencias

- [ ] `LICENSE` y `THIRD_PARTY_NOTICES.md` están incluidos.
- [ ] Se incluyen los textos de WUT, SDL2, curl, mpg123 y libjpeg-turbo.
- [ ] Se adjunta el código fuente exacto de mpg123 usado en el binario.
- [ ] Se adjunta todo el código fuente y los scripts necesarios para volver a enlazar la aplicación.
- [ ] Las versiones de dependencias coinciden con las notas del lanzamiento.

## Paquete

- [ ] El archivo final es `.wuhb` y abre desde Aroma.
- [ ] Icono, nombre, autor, imagen de TV e imagen del GamePad son correctos.
- [ ] No se dejan versiones anteriores que creen iconos duplicados.
- [ ] Se publica SHA-256 del `.wuhb` y del archivo de fuentes.

## Publicación

- [ ] Las notas indican que es homebrew no oficial.
- [ ] Se enumeran formatos y limitaciones conocidas.
- [ ] Hay formularios para errores y solicitudes sobre emisoras.
- [ ] La donación se describe como voluntaria y no concede acceso a contenidos.
